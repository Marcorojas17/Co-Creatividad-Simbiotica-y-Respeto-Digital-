# Co-Creatividad-Simbiótica-y-Respeto-Digital

Repositorio base para un visor cymático PWA, con diseño glass, simulación de frecuencia y controles de auditoría.

## Inicio local

```bash
python tools/audit.py
python -m http.server 8000
```

Abre `http://localhost:8000/`. Los artefactos criptográficos se incluyen como placeholders y se reemplazan en CI con claves configuradas.
